점과 도형의 이동 실험실 — 빠른 시작

1. ZIP 압축을 풉니다.
2. index.html 파일을 Chrome 또는 Safari에서 엽니다.
3. 처음에는 P(-2,3), 가로 +3, 세로 -2가 입력되어 있습니다.
4. [이동 시작]을 누릅니다. P′(1,1)에 도착하는 모습을 확인합니다.
5. [다시 보기]는 같은 움직임만 재생합니다.
6. [여기서 이어 이동]은 지금 도착한 위치에서 한 번 더 이동합니다.

점이나 식을 직접 바꿀 때:
  좌표 또는 방정식 입력 → [출발점 적용] / [새 도형 적용]
  → 이동량이나 대칭 기준 선택 → [이동 시작]

메뉴:
  점의 평행이동 / 점의 대칭 / 도형의 평행이동 / 도형의 대칭이동

도형 예:
  y=2x+1
  x=2
  (x-1)^2+(y-2)^2=4
  y=x^2

대칭축 직접 입력 예:
  x+y-1=0

GitHub Pages:
  새 저장소의 맨 위에 index.html 업로드
  → Settings → Pages → Deploy from a branch
  → main → /(root) → Save
  ※ ZIP 자체가 아니라 압축을 푼 파일을 올립니다.
  ※ Pages에 게시하면 일반적으로 외부 공개 사이트가 됩니다.

Streamlit:
  app.py, index.html, requirements.txt를 같은 폴더에 업로드
  → Main file path: app.py
  → Secrets / API 키는 필요 없습니다.
  ※ Streamlit용 파일은 포함했지만 실제 Streamlit 서버 구동·Cloud 배포는 미검증입니다.

새로고침하면 현재 위치와 이동 기록이 초기화됩니다.
기록을 남기려면 [이동 기록 → 기록 파일 저장]을 사용하세요.
배지와 보기 설정은 브라우저 저장 허용 시에만 유지됩니다.

움직임이 부담스럽다면 [보기 설정 → 움직임 줄이기]를 켜세요.
휴대폰에서는 [실험 설정]을 눌러 입력창을 펼칠 수 있습니다.

지원: 정수·소수·분수, 일차·이차 다항 방정식 한 개, 직선 대칭축.
미지원: 여러 식·정의역 제한·삼각함수·지수로그·변수 분수식.

자세한 내용은 README.md와 docs/검증보고서.md를 확인하세요.
