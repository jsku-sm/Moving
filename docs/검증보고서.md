## 주요 검증 내용

(-2,3)을 (+3,−2)만큼 이동하면 (1,1)에 도착하며, 다시 보기를 해도 이동 횟수가
늘어나지 않습니다. 그 위치에서 (−2,+1) 이동하면 (−1,2)가 됩니다. 실행 취소와
초기화는 각각 이전 상태와 최초 상태로 돌아갑니다.

음수 영역의 양의 방향, 0 이동, 5/2와 −1/2 입력, 1/3+2/3의 정확한 결과,
가로·세로 분리 경로와 직선 경로를 확인했습니다.

점 (2,3)의 x=1 대칭은 (0,3), x+y−1=0 대칭은 (−2,−1)입니다. 대칭축 위의 점,
원점 대칭, 점 (h,k) 대칭도 검증했습니다. 점 대칭에 가짜 대칭축을 그리지 않습니다.

원의 평행이동·대칭이동, 직선의 평행이동, 수직선, y=x²를 y=x에 대해 대칭이동한
x=y²의 양쪽 가지, 겹치는 도형의 안내를 확인했습니다. 고정된 꼭짓점만 보여주지 않고
움직이는 대표점 Q(−1,1) → Q′(1,−1)를 선택하는 것도 확인했습니다.

일반 이차곡선, 쌍곡선, 교차 직선, 평행 직선, 한 점으로 퇴화한 도형의 렌더링 경로에
NaN/Infinity가 없는지 확인했습니다. 일부 일반 곡선의 대표점은 근삿값이며, 이 검사는
모든 극단적 계수에서 전문 CAD 수준의 곡선 정밀도를 보증하는 검사가 아닙니다.

잘못된 수식, 변수 분모, 삼각함수, 3차식, 실수 해가 없는 식, 좌표평면 전체를 나타내는
항등식, 곡선 대칭축은 앱을 중단하지 않고 오류를 안내합니다.

도전 문제의 입력 잠금, 예상 답/이유 판정, 서로 다른 문제에 대한 배지, 자유 실험 복귀,
도움말, 실제 시간 기반 재생과 일시정지, 일시정지 상태에서 입력 수정 시 미완료 변환
취소를 확인했습니다.

## 검증의 한계

제작 환경에서는 외부 패키지 설치 네트워크가 연결되지 않아 Streamlit을 설치해
서버를 구동하지 못했습니다. 따라서 Streamlit 래퍼는 공식 HTML iframe API를 이용해
작성하고 Python 문법 검사 및 브라우저 iframe 실행까지 확인했지만,
Streamlit 자체의 런타임·Cloud 배포는 별도 확인이 필요합니다.

클립보드, PNG 파일 저장, 예제 URL, 로컬 저장의 실제 동작은 브라우저 보안·학교 기기
정책·호스팅 형태에 영향을 받습니다. 모든 실제 기기/호스팅 조합에서 검증한 것은 아닙니다.
PNG 생성 코드에는 실패 안내를 넣었고, 클립보드는 복사 대체 흐름을 제공합니다.

이 테스트 결과는 제시한 검증 경로에 대한 결과이며 모든 가능한 수식, 모든 브라우저,
수업 효과 또는 개념 숙달을 보증하는 결과가 아닙니다.
