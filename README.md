# 점과 도형의 이동 실험실

공통수학2의 점·도형 평행이동과 대칭이동을 관찰하는 독립형 학습 웹앱입니다.

**가장 간단한 사용법: `index.html`을 브라우저로 열면 됩니다.**
CSS, JavaScript, 수학 계산부, 좌표판을 한 파일에 포함했습니다. 기본 웹앱에는 Python, Node.js, API 키, 외부 데이터베이스, CDN, 로그인 설정이 필요하지 않습니다.

## 1. 실행 방법

### A. 먼저 내 컴퓨터에서 확인하기

ZIP 압축을 풀고 `index.html`을 Chrome 또는 Safari에서 여세요. 파일을 두 번 눌러 코드 편집기가 열린다면 파일을 우클릭하여 브라우저로 여세요. 인터넷 연결 없이도 기본 실험 기능을 사용할 수 있습니다. 이 방식은 웹에 공개하는 것이 아닙니다.

처음 입력된 예제는 `P(-2, 3)`, 가로 `+3`, 세로 `-2`입니다. **이동 시작**을 누르면 `P′(1, 1)`에 도착합니다.

### B. GitHub Pages로 학생에게 링크 공유하기

기존 수업용 대시보드에 덮어쓰지 않고 별도 저장소에 올려 사용하는 구성입니다.

1. 새 GitHub 저장소를 만들고, `index.html`을 저장소의 맨 위에 업로드합니다. ZIP 자체를 올리는 것이 아니라 압축을 푼 파일을 올립니다.
2. 저장소의 **Settings → Pages → Build and deployment**로 갑니다.
3. **Source: Deploy from a branch**, **Branch: main**, **폴더: /(root)**를 선택하고 저장합니다.
4. GitHub가 표시하는 실제 게시 주소를 확인하여 학생에게 공유합니다.

`.nojekyll`도 함께 올릴 수 있습니다. 수정·검증용 소스와 문서가 필요하면 ZIP 안의 전체 폴더를 같은 구조로 올리세요. `src` 폴더를 올리지 않아도 완성된 `index.html` 하나로 실행됩니다.

**주의:** 일반적인 GitHub Pages 게시 주소는 외부에서 접근할 수 있는 공개 사이트입니다. 저장소를 비공개로 설정하는 것만으로 웹페이지까지 비공개가 된다고 생각하면 안 됩니다. 이 결과물은 아직 어떤 외부 저장소나 사이트에도 자동 업로드·배포하지 않았습니다. 비공개 검토 중에는 로컬 파일로 사용하세요.

### C. Streamlit으로 실행하기

기존에 사용하던 Streamlit 배포 환경을 위한 `app.py`도 포함했습니다. 이 파일은 같은 웹앱을 iframe에 표시하는 실행용 래퍼입니다. 계산과 애니메이션은 브라우저에서 동일하게 작동합니다.

필수 파일을 **같은 폴더**에 올리세요.

```text
app.py
index.html
requirements.txt
```

Streamlit Community Cloud에서 해당 저장소를 선택하고 **Main file path를 `app.py`**로 지정하세요. 이 앱은 Secrets 설정을 사용하지 않습니다. `src/app.js`를 실행 파일로 선택하면 안 됩니다.

로컬 Python 환경에서는 다음과 같이 실행합니다.

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

화면을 짧은 iframe에 잘라 넣지 않도록 높이 1500과 내부 스크롤을 지정했습니다. 세로 태블릿·휴대폰에서는 앱 내부를 아래로 스크롤하세요. Streamlit 래퍼에서는 **예제 링크** 기능이 제한되며, 직접 게시한 GitHub Pages 화면에서 사용하세요.

**검증 범위:** 브라우저의 iframe/srcdoc 안에서 앱이 초기화되고 조작되는 것은 확인했습니다. 제작 환경에서 Streamlit 패키지를 설치할 네트워크 연결이 제공되지 않아 실제 Streamlit 서버 구동·Community Cloud 배포는 확인하지 못했습니다. `app.py`의 Python 문법 검사는 통과했습니다.

## 2. 네 가지 메뉴

| 메뉴 | 입력 | 관찰할 수 있는 내용 |
|---|---|---|
| 점의 평행이동 | 점의 x, y / 가로 a / 세로 b | 한 칸씩 이동하는 말, 방향, 자취, 누적 이동량, 최종 좌표 |
| 점의 대칭 | 점의 x, y / 대칭축 또는 중심 | 굵은 점선 기준, 부드러운 강조, 수선, 같은 거리, 대응점 |
| 도형의 평행이동 | 도형의 방정식 / a, b | 도형 전체와 대표점의 이동, 중심·좌표 변화, 최종 방정식 |
| 도형의 대칭이동 | 도형의 방정식 / 대칭 기준 | 원본과 결과 비교, 대표점의 대응, 축까지 거리, 최종 방정식 |

가로·세로 1단위의 길이는 항상 같습니다. 기본 체스판은 한 칸 1단위이며, 확대·축소에 따라 눈금 간격이 달라지면 좌표판 아래의 **한 칸 ○단위**를 확인합니다. 점은 칸의 가운데가 아니라 좌표 교차점에 놓입니다.

작은 움직임도 보이도록 실행 전에 출발·도착 위치에 맞춰 화면을 조정합니다. 재생 도중에는 자동으로 계속 화면을 이동시키지 않습니다. 사용자는 좌표판을 끌어서 이동하거나 +, −, 화면 맞추기를 사용할 수 있습니다. 터치 화면의 두 손가락 확대·축소도 처리합니다.

## 3. 처음 사용하는 학생에게

**따라 하기**에서는 기본 예제를 한 단계씩 관찰합니다. **자유 실험**에서는 원하는 값과 식을 입력합니다. **도전하기**에서는 지정된 문제의 결과와 이유를 예상하여 확인합니다. 세 방식 모두 동일한 계산·시각화 엔진을 사용하며, 기본 예제 설명을 끝내야만 자유 실험에 갈 수 있는 구조가 아닙니다.

숫자를 바꾼 뒤에는 **출발점 적용** 또는 **새 도형 적용**을 먼저 누릅니다. 이동 조건은 적용 버튼 없이 바로 바꿀 수 있습니다. 방향 버튼은 이동량의 부호를 바꾸며, +/− 버튼은 이동량을 1만큼 조절합니다.

도전 문제는 메뉴당 4개, 총 16개의 예제로 구성했습니다. 서로 다른 문제 두 개의 결과와 이유를 맞히면 해당 메뉴의 배지가 생깁니다. 힌트는 세 단계로 제공하며, 배지는 연습 기록이지 성적·숙달도 판정이 아닙니다.

`좌표가 처음이라면`에는 좌표의 순서, 방향의 부호, 점의 이동과 식의 대입 차이, 축 대칭과 점 대칭의 차이를 설명했습니다.

## 4. 재생 버튼의 차이

| 버튼 | 역할 |
|---|---|
| 이동 시작 / 여기서 이어 이동 | 현재 점·도형에 입력한 변환을 한 번 적용 |
| 일시정지 / 계속 | 현재 애니메이션을 멈추거나 계속 재생 |
| 한 단계씩 | 설명 한 단계 또는 한 이동 단위의 끝으로 이동 |
| 다시 보기 | 직전 움직임을 재생할 뿐, 변환을 추가 적용하지 않음 |
| 실행 취소 | 완료된 직전 이동 한 번을 되돌림. 미완료 재생 중에는 그 재생만 취소 |
| 처음으로 | 현재 실험의 최초 점·도형으로 복귀하고 그 실험 기록 초기화 |

실행 중에는 출발점·변환 조건 입력을 잠급니다. 일시정지한 후 조건을 수정하면 미완료 미리보기가 취소되고, 마지막으로 완료된 현재 상태에서 새 조건을 적용할 수 있습니다.

점의 두 메뉴는 현재 점을 공유하고, 도형의 두 메뉴는 현재 도형을 공유합니다. 따라서 평행이동 후 대칭이동을 이어서 해 볼 수 있습니다.

## 5. 입력 가능한 수와 식

좌표·이동량·대칭 중심의 새 입력은 −100부터 100까지이며 정수, 소수, 분수가 가능합니다.

```text
-2
0.5
1/3
-5/2
```

도형은 **x, y의 일차·이차 다항 방정식 한 개**를 입력합니다.

```text
y=2x+1
x=2
(x-1)^2+(y-2)^2=4
y=x^2
x=y^2
x^2+2xy+3y^2=4
xy=1
```

`x²`와 `x^2`, `2x`와 `2*x`를 모두 해석합니다. 대칭축은 x축, y축, y=x, y=−x, x=h, y=k, 또는 일반 직선의 방정식으로 설정할 수 있습니다. 원점과 점 (h,k)에 대한 대칭도 제공합니다.

```text
x+y-1=0
2x+3y=6
```

삼각함수, 지수·로그함수, 변수의 분수식, 여러 방정식을 결합한 픽토그램, 정의역·범위 제한은 이번 버전에서 지원하지 않습니다. 곡선을 대칭축으로 입력할 수도 없습니다. 지원하지 않는 식이나 실수 해가 없는 도형을 입력하면 안내문이 나타납니다.

수학적으로 같은 방정식은 0이 아닌 상수배까지 정규화하여 도전 답안을 비교합니다. 임의의 동치 변형이나 정의역이 다른 함수 표현을 판정하는 범용 증명기는 아닙니다.

## 6. 수학적 구현

좌표·입력 계수·평행이동·대칭이동의 식은 BigInt 유리수 연산을 사용합니다. 변수 치환을 문자열 순서대로 하지 않고 다항식 구조에 **동시에 대입**합니다. `eval` 또는 `Function`으로 사용자 입력을 실행하지 않습니다.

```text
점의 평행이동:       (x, y) → (x+a, y+b)
도형의 평행이동:     F(x−a, y−b)=0
x축 대칭:           (x, y) → (x, −y)
y축 대칭:           (x, y) → (−x, y)
원점 대칭:          (x, y) → (−x, −y)
y=x 대칭:           (x, y) → (y, x)
y=−x 대칭:          (x, y) → (−y, −x)
x=h 대칭:           (x, y) → (2h−x, y)
y=k 대칭:           (x, y) → (x, 2k−y)
점 (h,k) 대칭:      (x, y) → (2h−x, 2k−y)
```

일반 직선 Ax+By+C=0에 대해서는 수선의 발을 구해 대응점을 계산합니다. 원점·점 대칭에 가짜 대칭축을 표시하지 않습니다. 대칭축 위의 점, 대칭 후 겹치는 도형, 0만큼의 평행이동도 처리합니다.

도형의 대표점이 대칭축 위에서 제자리인 경우에는 가능한 한 실제로 움직이는 다른 대표점을 선택합니다. 예를 들어 y=x²의 y=x 대칭에서 원점만 보여주지 않고 Q(−1,1) → Q′(1,−1)의 대응을 볼 수 있습니다. `다른 대표점도 보기`를 켜면 나머지 대표점도 표시됩니다.

SVG 좌표판은 부동소수점으로 렌더링되며, 일반 이차곡선의 일부 대표점이나 무리수 거리는 근삿값을 사용하고 ≈로 표시합니다. 애니메이션 중간 좌표도 근사 표시입니다. 화면 렌더링은 정확한 유리수 식 계산과 구분합니다. 극단적으로 큰 계수·매우 가느다란 곡선의 픽셀 단위 정밀도까지 보장하는 전문 CAD 도구는 아닙니다.

## 7. 저장·공유·접근성

앱이 별도의 서버에 학생 이름·학번·학습 내용을 보내거나 AI API를 호출하지 않습니다. 완료된 이동 기록은 탭 안의 메모리에 보관하고 텍스트 파일로 저장할 수 있습니다. 현재 위치와 이동 기록은 새로고침하면 초기화됩니다.

브라우저가 로컬 저장을 허용하면 배지와 보기 설정만 그 브라우저에 남습니다. 시크릿 모드, 학교 기기 정책, iframe 저장 제한 등에 따라 새로고침 후 유지되지 않을 수 있습니다. 기기 간 동기화·교사 실시간 수집 기능은 없습니다.

좌표판 PNG 저장과 결과 복사 기능을 제공합니다. 브라우저의 다운로드·클립보드 정책에 따라 제한될 수 있습니다. GitHub Pages 등 HTTP(S)로 직접 연 화면에서는 현재 출발 위치·변환 조건을 담은 예제 링크를 만들 수 있습니다. 로컬 파일과 Streamlit iframe에서는 링크 공유 대신 좌표판·실험 기록 저장을 사용합니다.

축과 최종 결과의 강조는 느린 밝기 변화 두 번으로 제한했습니다. 기기의 움직임 줄이기 설정을 반영하고, 앱의 보기 설정에서도 바꿀 수 있습니다. 이 모드에서는 한 단계씩 정지 화면으로 확인합니다. 입력창 밖에서는 Space로 정지/계속, 오른쪽 화살표로 다음 단계를 실행합니다.

## 8. 검증 결과와 아직 확인하지 않은 환경

- 핵심 테스트에서 처리되지 않은 JavaScript 오류 없음.
- 실물 iPad Safari, 실제 GitHub Pages 게시, 실제 Streamlit 서버 실행·Cloud 배포는 미확인.

자세한 항목은 `docs/검증보고서.md`, 결과 데이터는 `tests/math-results.json`과 `tests/browser-results.json`에 있습니다. 스크린샷은 `docs`에 포함했습니다. 일부 보조 기능의 실제 호스팅 환경별 동작은 별도 확인이 필요합니다.

## 9. 파일 구성과 수정

```text
index.html                 완성된 독립 실행 웹앱
app.py                     선택: Streamlit 실행용 래퍼
requirements.txt           선택: Streamlit 의존성
.streamlit/config.toml     선택: Streamlit 테마·통계 수집 설정
src/template.html          화면 구성 원본
src/styles.css             반응형 디자인 원본
src/math.js                정확한 유리수·다항식 계산
src/graph.js               SVG 좌표판·도형·자취·라벨
src/app.js                 입력·학습 모드·재생·기록 상태 관리
build.py                   원본을 index.html 하나로 합치는 도구
빠른시작.txt               짧은 실행 안내
README.md                  전체 사용·배포 안내
TESTING.md                 개발자용 재현 절차
spec.md                    구현 범위 요약
CHANGELOG.md               변경 기록
LICENSE-NOTICE.txt         포함 구성요소 안내
```

`src`를 수정한 뒤에는 다음 명령으로 완성 파일을 다시 만듭니다. 수정 없이 사용하는 경우 실행할 필요가 없습니다.

```bash
python build.py
```
